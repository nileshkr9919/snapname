# Changelog

## 1.0.0
- New screenshots are renamed to what they show, using a local Ollama vision model (default `gemma4`).
- A one-line description is saved where Spotlight indexes it, so ⌘-Space finds screenshots by their contents.
- **Name Existing Screenshots** renames the backlog on request.
- Files are only renamed, never edited or deleted; the original name is kept in an extended attribute.
- Follows the screenshot location set in the Screenshot app; Pause and Open at Login in the menu.
